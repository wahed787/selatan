Selatan tea-ชาใต้ — รุ่น PIN 6 หลัก พร้อมตั้งค่าลิสต์

วิธีอัปโหลด
1. แตกไฟล์ ZIP แล้วอัปโหลด index.html ไปยังโฟลเดอร์เว็บไซต์ของโฮสต์
2. เปิดเว็บไซต์ผ่าน HTTPS เพื่อให้ระบบเข้ารหัส PIN ทำงานได้
3. ไม่ต้องติดตั้ง Node.js ฐานข้อมูล หรือ API key

ข้อมูลเดิม
ข้อมูลและ PIN อยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้อยู่ในไฟล์แอพ
ก่อนย้ายเว็บไซต์ ให้เปิดเว็บเดิม ปลดล็อก แล้วกด “สำรองข้อมูลทั้งหมด”
เปิดเว็บใหม่ ตั้ง PIN แล้วกด “นำเข้าข้อมูลสำรอง” เลือกไฟล์ JSON ที่สำรองไว้
ไฟล์สำรองจะรวมรายการบัญชีและการตั้งค่าลิสต์ทั้งหมด

ข้อควรรู้
เว็บไซต์ใหม่นี้ใช้ PIN ที่คุณตั้งเอง ไม่มีหน้าล็อกอิน ChatGPT ของ Sites
แต่ละเครื่องและแต่ละโดเมนเก็บข้อมูลแยกกัน ไม่ซิงก์อัตโนมัติ
ไฟล์สำรอง JSON ไม่ได้เข้ารหัส ควรเก็บไว้ในที่ปลอดภัย
ฟอนต์ Sarabun โหลดจาก Google Fonts หากโหลดไม่ได้จะใช้ฟอนต์สำรอง
ค่าบริการของโฮสต์ที่เลือกเป็นไปตามเงื่อนไขของผู้ให้บริการนั้น
