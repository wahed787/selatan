Selatan tea-ชาใต้ — ไฟล์รุ่น V2

สิ่งที่ปรับ
1. แดชบอร์ดรวมทุกเดือน เลือกดูรายเดือนได้ พร้อมตารางสรุปและกราฟ
2. แยกสินค้าซื้อเข้าและสินค้าขาย สินค้าขายเริ่มต้นเป็น “ชาใต้”
3. ตั้งราคาซื้อแยกตามร้านขายส่ง และราคาขายแยกตามลูกค้า/ร้านที่ขายให้
   ราคาผูกกับสินค้า ร้าน และหน่วยนับ ถ้าไม่เลือกร้านจะใช้ราคาทั่วไป
4. หน้าบันทึกรวมการเลือกชื่อสินค้าและร้านไว้ในช่องหลัก พร้อมปุ่ม + เพิ่ม
5. หน่วยนับเป็นลิสต์ อยู่ถัดจากจำนวน และเพิ่มหน่วยใหม่ได้
6. ไม่มีช่องต้นทุนต่อหน่วยในยอดขาย

สูตรกำไรของรุ่นนี้
ยอดขาย − ค่าใช้จ่ายทั้งหมดที่บันทึก (รวมเงินซื้อสินค้าเข้า)
ไม่มีการหักต้นทุนต่อหน่วยซ้ำ และไม่ได้ปรับมูลค่าสินค้าคงเหลือทางบัญชี
ตัวเลขกำไรย้อนหลังจึงอาจเปลี่ยนจากรุ่นเดิมที่เคยหักต้นทุนต่อหน่วย

วิธีอัปเดต
1. เปิดเว็บรุ่นเดิม ปลดล็อก แล้วกด “สำรองข้อมูลทั้งหมด” เก็บไฟล์ JSON ไว้ก่อน
2. เก็บสำเนา index.html รุ่นเดิมไว้ด้วย
3. แตกไฟล์ ZIP แล้วใช้ index.html ที่อยู่ใน ZIP ได้เลย
   หากดาวน์โหลดเฉพาะ selatan-tea-v2.html ให้เปลี่ยนชื่อเป็น index.html
4. อัปโหลดทับไฟล์ index.html ในเว็บไซต์เดิมที่ใช้ HTTPS
5. รีเฟรชหน้าเว็บ ใช้ PIN เดิม หากยังอยู่โดเมนและเบราว์เซอร์เดิม
6. หากข้อมูลไม่แสดง ให้นำเข้าไฟล์สำรองผ่าน “นำเข้าข้อมูลสำรอง”

ตั้งค่าราคา
เปิด ตั้งค่า > ราคาซื้อ / ราคาขาย
เลือกราคาขายหรือราคาซื้อเข้า แล้วเลือกสินค้า ร้าน หน่วยนับ และราคาต่อหน่วย
เลือก “ราคาทั่วไป” หากต้องการใช้ราคาเดียวกันหลายร้าน
เมื่อบันทึกรายการ ระบบจะเติมราคาที่ตรงกับสินค้า ร้าน และหน่วยนับ
แก้ราคาเฉพาะรายการได้ โดยไม่เปลี่ยนราคามาตรฐาน

ข้อมูลและการตั้งค่า
อ่านข้อมูลและไฟล์สำรองรุ่นเดิมได้ โดยคงรายการบัญชีและข้อมูลราคาเดิมไว้
การแก้ลิสต์และราคามาตรฐานไม่เปลี่ยนรายการที่บันทึกไว้ย้อนหลัง
สินค้าเดิมจากลิสต์รวมจะอยู่ในสินค้าซื้อเข้า ส่วนสินค้าขายเริ่มต้นมี “ชาใต้”
ข้อมูลและ PIN เก็บแยกแต่ละเบราว์เซอร์/โดเมน ไม่มีการซิงก์ข้ามเครื่อง
ไฟล์สำรอง JSON ไม่เข้ารหัส ควรเก็บไว้ในที่ปลอดภัย

สถานะการตรวจสอบ
ผ่านการตรวจไวยากรณ์ JavaScript และทดสอบตรรกะด้วยข้อมูลจำลองแล้ว:
- การอ่านข้อมูลเข้ารหัสและ PIN รุ่นเดิม
- แดชบอร์ดรวมทุกเดือนและรายเดือน โดยไม่หักต้นทุนต่อหน่วยซ้ำ
- ราคาซื้อ/ราคาขายตามร้านและหน่วยนับ รวมราคาทั่วไป
- การเพิ่มรายการจากปุ่ม + และการบันทึกยอดขาย/ค่าใช้จ่าย
- ราคาเดิมของรายการย้อนหลังไม่เปลี่ยนตามราคามาตรฐาน
- การบันทึกแบบเข้ารหัส การสำรองรุ่น V3 และนำเข้าไฟล์รุ่นเดิม
ยังไม่ได้เปิดทดสอบหน้าตาและการกดใช้งานในเบราว์เซอร์จริง
เนื่องจากเครื่องมือเบราว์เซอร์ของแชตขัดข้อง
ควรทดลองบนเว็บสำเนาก่อนอัปโหลดแทนไฟล์ใช้งานจริง
